安装客户端

按使用方式选择一个入口。CLI 和 MCP 需要 Python 3.10 或更高版本，以及可安装第三方依赖的 pip 环境。先将所选文件下载到同一个目录，在该目录打开终端。以下安装命令适用于 Linux 和 macOS。

服务器内网下载

可访问实验室网络时，在安装客户端的电脑上从 @platform-url@/downloads/ 取包。也可以点击下面各组件的下载链接，通过已打开的工作台保存文件。

gpu_server=@platform-shell@
# CLI 用第一个 wheel，MCP 用两个 wheel，Skill 用最后一个文件。
curl -fSLO "$gpu_server/downloads/@gpu-platform-client@"
curl -fSLO "$gpu_server/downloads/@gpu-platform-mcp@"
curl -fSLO "$gpu_server/downloads/SKILL.md"

CLI · 在终端操作

下载 CLI 安装包，在运行命令的电脑上安装。

python3 -m venv "$HOME/.local/share/gpu-workbench/venv"
. "$HOME/.local/share/gpu-workbench/venv/bin/activate"
python -m pip install "./@gpu-platform-client@"
gpu-jobs --help
下载 CLI 安装包

MCP · 让 Agent 调用工作台

在运行 MCP 客户端的电脑上安装 MCP 和它使用的共享客户端库。完成安装后，按下方「连接自己的账号」注册到 Codex。

python3 -m venv "$HOME/.local/share/gpu-workbench/venv"
. "$HOME/.local/share/gpu-workbench/venv/bin/activate"
python -m pip install "./@gpu-platform-client@" "./@gpu-platform-mcp@"

其他 MCP 客户端选择 stdio，启动命令填上面环境中 gpu-platform-mcp 的绝对路径，环境变量 GPU_PLATFORM_URL 填工作台地址。

下载 MCP 安装包 · 下载共享客户端库

Skill · 给 Agent 添加 GPU 作业规则

如果 Agent 已连接工作台 MCP，或已能从 PATH 调用 gpu-jobs，只需装这一个文件，再打开新的 Agent 会话。

mkdir -p "$HOME/.agents/skills/gpu-jobs"
install -m 0644 ./SKILL.md "$HOME/.agents/skills/gpu-jobs/SKILL.md"
下载 SKILL.md

通过 SSH 取包

如果安装客户端的电脑无法打开下载页，可使用平时登录 GPU 服务器的 SSH 主机别名。下面三行 scp 分别获取 CLI 包、MCP 包和 Skill，按需执行。MCP 需要两个 wheel。

printf 'GPU 服务器 SSH 登录目标（用户名@主机或别名）: '
read -r gpu_host
scp "${gpu_host}:/opt/gpu-platform/web/downloads/@gpu-platform-client@" .
scp "${gpu_host}:/opt/gpu-platform/web/downloads/@gpu-platform-mcp@" .
scp "${gpu_host}:/opt/gpu-platform/web/downloads/SKILL.md" .

连接自己的账号

在实验室内网可直接使用下列服务器地址。使用 SSH 转发时，把这个变量改为运行客户端的电脑上已建立的转发入口。

export GPU_PLATFORM_URL=@platform-shell@
gpu-jobs platform

使用 Codex 时，在已安装 MCP 的虚拟环境运行：

codex mcp add gpu-platform --env GPU_PLATFORM_URL="$GPU_PLATFORM_URL" -- "$VIRTUAL_ENV/bin/gpu-platform-mcp"

CLI 和 MCP 默认读取当前电脑上的 ~/.config/gpu-platform/access.token。在 haigpu9 上登录自己的 Linux 账号即可使用已分配的令牌。在个人电脑上运行时，通过 SSH 将自己的令牌复制到同一路径并设为仅本人可读，或用 GPU_PLATFORM_TOKEN_FILE 指定已有凭据文件。

提交任务的工作目录和解释器均填写服务器路径。
